# my-approaches

Java practice repository organized by categories and approach styles.

## Approach Types by Folder

### 1) Binary_bits
- Bit manipulation
- Brute force bit-by-bit simulation

### 2) good_questions
- Brute force vs optimized approach comparison
- Two pointers
- Hashing / set-based lookup
- Majority voting (Moore Voting Algorithm)
- Array scanning and in-place updates

### 3) Linked List
- Basic linked list construction and insertion
- Fast and slow pointer technique
- In-place reversal
- Node deletion and partitioning patterns
- Brute force vs optimized palindrome check

### 4) Mathematical
- Formula-based math solutions
- Modulo and divisibility checks
- Counting / simulation
- Number property checks (power, square root, parity)

### 5) try
- Practice implementations of common patterns
- HashSet-based duplicate detection and brute force alternatives
- Array transformations (sorted squares)
- Number-based checks (happy, palindrome, missing/single number)
